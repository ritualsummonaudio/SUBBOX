# SUB BOX ONYX

This repository holds the current source update for the supplied stable ONYX 1.2.12 Windows VST3, using the older ONYX 1.2.7 source as a documented reference.

Requested update: permanent SUB 20–60 Hz and BASS 60–150 Hz lanes shared with SOLO; SBO −0.99 dBFS soft entry and −0.1 dBFS hard ceiling; SC default OFF; lower RAM activity and fixed latency.

Implementation and validation are being prepared on a development branch. No customer release or FL Studio qualification is claimed by this initialization commit.
